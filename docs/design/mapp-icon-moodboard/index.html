мэпп↗

Мудборд иконки.
Найти свой путь — и свой знак.

12 референсов · 3 направления · Design 30 Club ↗

Буква «м» + пространство + движение.
Иконка должна быстро узнаваться на телефоне и говорить о понятном, дружелюбном сервисе для жизни в кампусе.

01

Знак и пространство

Самое близкое направление для мэпп: одна форма, которую можно прочитать как «м», коридор или поворот маршрута.

Оригинал ↗
Mark · meyo

Чёрное / белое

Негативное пространство связывает две формы. Для мэпп — прорезать маршрут внутри буквы «м», сохранив один цельный силуэт.

Оригинал ↗
Екатерина Чещевая · 4

Два смысла в одном знаке

Треугольник и петля собраны в компактный символ. Для мэпп — совместить указатель направления с началом маршрута.

Оригинал ↗
Arina Dolgikh · icon_1

Ритм и симметрия

Повторяющиеся вертикальные элементы собираются в знак. Для мэпп — проверить ритм штрихов буквы «м» и план коридора; сократить число деталей.

Оригинал ↗
Egor · Container

Глубина без мелочей

Крупная белая фигура внутри цветной рамки. Для мэпп — один проход или дверной проём, который работает как пространственная буква.

02

Цвет и характер

Один узнаваемый объект и уверенная цветовая пара. Хорошая основа для иконки, заметной среди других приложений.

Оригинал ↗
Vova Krasilnikov · Frame 2136137740

Один объект

Оранжевый круг на светлой подложке. Для мэпп — точка «ты здесь» с небольшим объёмом; проверять, хватает ли уникальности без контекста.

Оригинал ↗
Marina Deschain · Frame 4

Контрастный силуэт

Тёмная крупная форма на лаймовом фоне. Взять соотношение фона и знака, а форму заменить собственной геометрией «м».

Оригинал ↗
Ilya Maksimov · Frame 43

Буква как образ

Белая надпись вписана в силуэт. Для мэпп — пробовать выразительную «м», а полное название оставить для крупных носителей.

Оригинал ↗
Roma Khlebnikov · day7

Плотная типографика

Буквы заполняют почти всю иконку. Референс для энергичного характера; для маленького размера свести композицию к одной букве.

03

Дружелюбный проводник

Если мэпп должен восприниматься как помощник студента: простой персонаж, связанный с навигацией.

Оригинал ↗
Tim · day1

Мягкая форма и эмоция

Крупные глаза и простой объём. Для мэпп — оживить точку на карте или букву «м», избегая мелких черт лица.

Оригинал ↗
Olga Ko · Dribbble shot - 1

Орбита вокруг центра

Центральный персонаж и кольцо дают ощущение движения. Для мэпп — путь вокруг точки назначения; оставить один маршрут.

Оригинал ↗
Artem Suprunov · Frame 71

Минимум линий

Свободный чёрный жест на белом поле. Для мэпп — маршрут, который складывается в улыбку или «м»; не переносить бейдж уведомления.

Оригинал ↗
Anton Nikitin · __1i

Персонаж из края формы

Лицо вырастает из нижнего края иконки. Для мэпп — дружелюбный силуэт из двух арок «м», без заимствования конкретного персонажа.

Первое направление для эскизов

«м» как маршрут

Начать с оранжевой подложки и светлой буквы «м». Внутренний просвет буквы превратить в путь с одним поворотом. Сравнить с обратной, светлой версией.

Опорные референсы: meyo — негативное пространство; 4 Екатерины Чещевой — объединение смыслов; icon_1 — ритм формы.

Проверка следующего этапа: 24 / 32 / 64 px, монохром, светлый и тёмный экран, ряд соседних приложений. Это направление для нового эскиза, не готовый логотип.

Изображения — работы участников Design 30 Club. Просмотрены 60 работ, в подборке сохранены полные превью с авторством и ссылками на оригиналы. Комментарии — разбор применимости к мэпп; готовые чужие знаки не предлагаются к переносу.
