# Мэпп — мудборд иконки

Источник: https://www.design30.club · отбор 08.09.2026. Просмотрены 60 работ из публичной галереи, отобраны 12.

Изображения — работы участников Design 30 Club, оставлены целиком с исходными подписями. Это референсы приёмов, не готовые иконки мэпп. Комментарии и рекомендации — авторский разбор для проекта.

## Знак и пространство

- [Mark — meyo](https://www.design30.club/ru/work/687f83fe-edaf-4c4c-a90a-28b53f95cd7f). Негативное пространство связывает две формы. Для мэпп — прорезать маршрут внутри буквы «м», сохранив один цельный силуэт.

- [Екатерина Чещевая — 4](https://www.design30.club/ru/work/56fa49f5-c712-4c53-bfa4-35b2bbebdab5). Треугольник и петля собраны в компактный символ. Для мэпп — совместить указатель направления с началом маршрута.

- [Arina Dolgikh — icon_1](https://www.design30.club/ru/work/2254aab8-3b85-43e8-99cc-4afa56dffc28). Повторяющиеся вертикальные элементы собираются в знак. Для мэпп — проверить ритм штрихов буквы «м» и план коридора; сократить число деталей.

- [Egor — Container](https://www.design30.club/ru/work/2348e2b9-c732-4c62-b866-fafcfd63997e). Крупная белая фигура внутри цветной рамки. Для мэпп — один проход или дверной проём, который работает как пространственная буква.

## Цвет и характер

- [Vova Krasilnikov — Frame 2136137740](https://www.design30.club/ru/work/6c6f3e74-9f7e-44a4-bbec-37ab66ee32d2). Оранжевый круг на светлой подложке. Для мэпп — точка «ты здесь» с небольшим объёмом; проверять, хватает ли уникальности без контекста.

- [Marina Deschain — Frame 4](https://www.design30.club/ru/work/c9cce5c8-89bd-4164-a669-6994bcd1f878). Тёмная крупная форма на лаймовом фоне. Взять соотношение фона и знака, а форму заменить собственной геометрией «м».

- [Ilya Maksimov — Frame 43](https://www.design30.club/ru/work/34e14530-f8df-4bbe-b05a-c049f9d672a5). Белая надпись вписана в силуэт. Для мэпп — пробовать выразительную «м», а полное название оставить для крупных носителей.

- [Roma Khlebnikov — day7](https://www.design30.club/ru/work/823a9d83-1a6f-4784-89eb-25baa1a7e027). Буквы заполняют почти всю иконку. Референс для энергичного характера; для маленького размера свести композицию к одной букве.

## Дружелюбный проводник

- [Tim — day1](https://www.design30.club/ru/work/251819a2-b805-4dd9-85d2-0e05eb72553d). Крупные глаза и простой объём. Для мэпп — оживить точку на карте или букву «м», избегая мелких черт лица.

- [Olga Ko — Dribbble shot - 1](https://www.design30.club/ru/work/17fc7231-3c18-46cb-b380-0708bc0e9649). Центральный персонаж и кольцо дают ощущение движения. Для мэпп — путь вокруг точки назначения; оставить один маршрут.

- [Artem Suprunov — Frame 71](https://www.design30.club/ru/work/c8fb7b44-c58b-439c-8ef9-eec9d546ecfe). Свободный чёрный жест на белом поле. Для мэпп — маршрут, который складывается в улыбку или «м»; не переносить бейдж уведомления.

- [Anton Nikitin — __1i](https://www.design30.club/ru/work/b8575b71-12ba-4512-b0b3-9fc9bcf2acb6). Лицо вырастает из нижнего края иконки. Для мэпп — дружелюбный силуэт из двух арок «м», без заимствования конкретного персонажа.

## С чего начать

Первый эскиз: оранжевая подложка, светлая буква «м», внутри — маршрут с одним поворотом. Сопоставить с плоской версией на светлом фоне. Проверить в 24, 32 и 64 px, монохроме и среди соседних иконок. Референсы: Mark / meyo, Екатерина Чещевая / 4, Arina Dolgikh / icon_1.
